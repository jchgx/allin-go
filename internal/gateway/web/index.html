系统提示词注入

在这里设置的提示词会在网关层强制注入到每个请求，客户端自己带什么 system 都压得住。

身份词屏蔽

上游会扫请求里的文本，认出第三方 Agent 的自我描述（例如「You are an AI agent powered by DeepSeek Harness」）后， 用 400 / code 11-128 拒掉整条请求。开启后，网关会把下面这些词在上下文里替换成中性说法，降低被认出的概率。
注意：上游的判定带自适应成分，同一份内容不同时刻结果可能不同 —— 这项功能是「降低概率」，不是「百分百免疫」； 网关同时保留了「改写消息开头后重发」的兜底。改完对下一个请求生效。
